# Project overview

This repository is a personal portfolio website for Rohish Shrees, focused on AMV editing and frontend creativity.

## Included pages
- `index.html` — landing page / home
- `about.html` — profile and story
- `proj.html` — project showcase with video cards
- `contact.html` — contact form and social links
- `style.css` — main styling for the site
- `script.js` — JavaScript for interactive behavior and small enhancements

## Run locally
1. Open `index.html` in a browser, or
2. Serve the project with a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes
- This is a frontend project using HTML, CSS, and JavaScript.
- JavaScript was added for the needed interactivity and polish, which is the correct fit for a browser-based portfolio.
- The project is designed to be simple, clean, and professional while still reflecting the creator's visual style.
